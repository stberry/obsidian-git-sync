### 전반적인 handler의 동작 시퀀스 (motor, tray 이동, tray 위치별 검사)

1. Empty rail에서 Stacker가 열리며 Empty Front Elevator에 트레이를 안착
2. Elevator를 내린 후 Stacker을 닫아 Tray를 한장만 내림
3. Empty rail indexer가 Tray를 Clamp하여 Empty Rear Elevator까지 이동
4. Empty Rear Elevator에서 밀어올린 Tray를 TFM Fork로 집어 올리고 TFM Top room에 Grip
5. TFM이 Loader rail로 이동하여 Loader Rear Elevator에 Tray 안착, 이때 Loader rail Indexer가 Loader rail 끝에 도착해 있어야 함
6. Loader rail의 Indexer가 Loader Front Elevator로 Tray를 이동

6~7 사이에 동시작업으로 Empty Rail에서 Empty tray하나가 Indexer로 Empty rear Elevator로 이동하여 TFM의 Top에 Grip
(영상 첨부)

<IFM\>
7. Loader rail gap이 Indexer에서 Tray를 IFM으로 이동
8. IFM의 Elevator가 Tray를 밑으로 내리고 top에 Grip (cover tray 역할)
9. Loader rail의 IFM에서 적재된 Loading tray 중 가장 밑에 있는 Tray를 Elevator로 내림 (Tray를 내릴때 Loader rail gap이 열림)
10. loading tray에서 검사를 위한 tray를 IFM bottom에 grip (package tray)
	1. loading tray에서 package tray를 계속 보충하며 검사 진행
11. IFM에서 cover tray를 package tray에 덮고 flip후 Elevator로 Loarder rail로 이동
12. 뒤집은 Package tray를 2d bottom으로 이동하여 2d bottom 촬영 (left top -> right bottom, horizontal)
13. 2d bottom 진행 후 3d bottom 촬영 (left top -> right bottom, horizontal)    
14. 촬영 완료 후 Loader rear elevator에 도착한 트레이를 TFM fork로 집어 TFM Top에 있는 Tray로 덮고 Good rail로 이동
15. Rail 이동 후 Flip (cover tray를 씌워 flip 후 top 촬영을 위해 이동)
16. 뒤집은 아래 Tray를 Top 촬영을 위해 Good rail에서 Indexer clamp 후 2d top 촬영
17. 2d top 촬영 후 3d top 촬영 (right bottom to left top, horizontal)
18. reject tray, buffer tray, good tray를 분류, reject에는 불량만, good에는 양품만 모으는 작업, 정렬과정중에 Empty tray한장을 Buffer로 사용
19. Tray에 reject or good이 꽉차면 배출, 두 칸 모두 아직 배출 이전이라면 새로운 burffer 추가
