TR 작성 가이드 공지

TR 리뷰중 잘못 작성된 TR 또는 버전 배포가 잘못되는 경우가 있어 바로잡고자 가이드를 안내드립니다.

현재 TR에는 Test Project Code가 만들어지고 있으며 1차 TR에서는 자동으로 생성되고 2차 TR부터는 1차 TR에 생성된 코드를 상속받아 사용하도록 되어있습니다.

그러나 이 Test Project Code가 같은 TR들이 다수 발견되어 추적해보니 아래 세가 경우로 정리되었습니다.

1. 같은날 두건이상 배포되는경우 가장 마지막 버전을 기준으로 TR을 작성한다.
	- 배포시 일정 기간을 두고 정기 배포를 하는것이 원칙입니다. 하지만 핫픽스 패치가 많은 본사 개발 특성상 배포기간을 하루로 하여 배포해야 합니다.
	- 예를 들어, 9월 29일 오전 1.1버전이 배포되고 9월 29일 오후 1.2버전이 배포된다면 1.2 버전으로 TR을 등록해주시고 의뢰항목에 모두 포함하여 작성해주시면 됩니다.
2. 같은날 핸들러, 비전이 동시에 배포되는 경우 하나의 TR로 작성한다.
	- 핸들러, 비전의 구분 없이 하나의 TR로 작성하여 배포해야 합니다.
	- 예를 들어, 9월 29일 핸들러와 비전이 모두 배포되는 경우 핸들러, 비전의 모든 정보를 포함하여 하나의 TR을 작성해야 합니다.
